Confidentialité

Ce que fait le code du site, et les limites des informations actuellement disponibles.

Version du 9 novembre 2026

Consultation du site

Le code de cette version ne met en place aucun compte utilisateur, outil de mesure d’audience, publicité, cookie applicatif, stockage local ou bouton de suivi social. Les polices et les visuels sont servis avec le site.

La consultation nécessite des requêtes réseau vers l’hébergeur. Celui-ci reçoit notamment l’adresse IP et les informations techniques nécessaires à ces échanges. Ses propres traitements sont décrits dans sa politique de confidentialité. Aucune durée de conservation ou pratique supplémentaire de l’hébergeur n’est affirmée ici sans confirmation.

Brouillon de message

La fonction « Préparer un message » utilise les champs nom, e-mail, sujet et message uniquement dans votre navigateur pour fabriquer un fichier texte à télécharger. Le code du formulaire n’envoie pas ces champs à un serveur et ne les enregistre pas dans le stockage applicatif du navigateur.

Le fichier téléchargé reste sous votre contrôle. Vous décidez de le conserver, de le supprimer ou de le transmettre vous-même. Le message de confirmation indique explicitement qu’aucun message n’a été envoyé.

Liens externes

Les liens vers les documents de l’hébergeur vous conduisent à son site. Les règles propres à ce service s’appliquent lorsque vous le consultez.

Questions et droits

Les éventuels traitements de données personnelles restent soumis au droit applicable, notamment au RGPD et à la loi Informatique et Libertés. Vous pouvez consulter la CNIL pour connaître vos droits.

Le contact public de l’éditeur n’a pas encore été communiqué. Il reste nécessaire de le compléter pour permettre les demandes concernant les traitements qui relèvent de sa responsabilité. Pour les traitements propres à Vercel, consulter les moyens de contact fournis dans sa politique officielle.
