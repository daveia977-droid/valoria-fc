# Publication Vercel de VALORIA FC

Le projet existant `valoria-fc` (équipe ROY TEAM, offre Hobby indiquée par l’utilisateur) est connecté à GitHub `daveia977-droid/valoria-fc`, branche `main`.

- Build : `npm run build -- --base=/`.
- Répertoire publié : `dist/`.
- Aucun token ou variable secrète nécessaire au site statique.
- Aucun service d’envoi, analytics, abonnement ou domaine à activer.

Vérifier la compilation et les tests avant de pousser main. Le push déclenche l’intégration Vercel existante ; contrôler ensuite le commit du déploiement, son statut READY et les ressources sur `https://valoria-fc.vercel.app/`. Ne pas confondre préparation locale, push et déploiement réussi.

Procédure et limites : [v1-publication.md](v1-publication.md). Le formulaire produit un brouillon local, pas un envoi d’e-mail. Les informations légales manquantes restent signalées dans les pages correspondantes.
