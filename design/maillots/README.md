# Sources de conception conservées

Ces fichiers sont des copies exactes des fichiers de travail existants, sans régénération :

- `domicile-v1.blend` : source Blender du prototype 3D déjà disponible ; texture de face intégrée, dos uni approuvé. Le site charge uniquement son export existant `public/models/domicile-v1.glb`.
- `domicile-v1-dos-maquette.svg` : proposition 2D historique ayant précédé la modélisation. Elle n’est pas utilisée pour fabriquer une fausse rotation.

La coupe du modèle reste approximative, construite à partir de la référence de face. Ces sources ne sont pas des patrons de confection ou des modèles industriels. Les trois autres tenues ne disposent pas d’un modèle 3D.
