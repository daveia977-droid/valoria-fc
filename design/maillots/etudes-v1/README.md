# Études V1 conservées avant publication du site

Ces copies exactes conservent les derniers travaux locaux, précédemment non enregistrés dans Git :

- `base-retenue/` : projet Blender, GLB et copie du script de l’étude avec plis retenue par l’utilisateur.
- `assouplie/` : projet Blender, GLB et rapport de contrôle de l’ajustement des épaules, des aisselles, de la taille et des manches.

Les modèles sont des **études incomplètes**, avec le nouveau dos encore en attente du PNG original. La source de face est conservée ; aucune apparence arrière n’est validée par ces études. Voir `docs/prototype-v1-tissu.md` et les constructeurs dans `tools/`.

Ces ressources de travail ne sont pas dans `public/` et ne sont pas publiées dans `dist/`. La mission GitHub Pages conserve le modèle servi par le site et ne remplace pas le maillot par un prototype incomplet. Tous les originaux locaux et la sauvegarde complète restent disponibles.
